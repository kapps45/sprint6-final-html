# Morse Text Converter

HTTP-сервис на Go для преобразования текста между обычным представлением и кодом Морзе.

Приложение предоставляет веб-интерфейс для загрузки данных и возвращает результат преобразования в виде файла.

## Возможности

- загрузка данных через веб-интерфейс;
- преобразование текста в код Морзе;
- обратное преобразование кода Морзе в текст;
- обработка русского алфавита;
- автоматическое определение формата входных данных;
- сохранение результата преобразования в файл.

## Архитектура

Проект разделён на несколько уровней:

- `server` — запуск и настройка HTTP-сервера;
- `handlers` — обработка HTTP-запросов и взаимодействие с веб-интерфейсом;
- `service` — определение типа входных данных и основная логика преобразования;
- `pkg/morse` — функции работы с кодом Морзе.

Основная логика приложения отделена от HTTP-слоя, что позволяет независимо тестировать компоненты.
