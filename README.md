📡 Morse Converter

HTTP-сервис на Go для обработки текстовых файлов и преобразования содержимого между обычным текстом и азбукой Морзе.

Приложение работает через веб-интерфейс, самостоятельно определяет формат входных данных и сохраняет результат обработки в файл.

🔧 Возможности
загрузка файлов через HTML-форму;
определение типа полученного содержимого;
преобразование текста в код Морзе;
обратный перевод кода Морзе в текст;
поддержка русского алфавита;
сохранение результата преобразования в локальный файл.
📁 Структура проекта
Компонент	Назначение
server	Настройка и запуск HTTP-сервера
handlers	Обработка запросов и загрузки файлов
service	Определение формата данных и основная логика преобразования
pkg/morse	Работа с кодом Морзе
