📡 Morse Converter

HTTP-сервер на Golang для загрузки файлов и автоматической конвертации текста в код Морзе и обратно.
🔧 Возможности

    Загрузка файла через HTML-форму
    Автоматическое определение содержимого (текст или код Морзе)
    Конвертация текста ↔ код Морзе (русский алфавит)
    Сохранение результата в локальный файл

📦 Структура проекта
Пакет 	Назначение
server 	Создание и настройка HTTP-сервера
handlers 	Обработчики для главной страницы и загрузки файлов
service 	Логика определения и конвертации данных
pkg/morse 	Библиотека конвертации Морзе (предоставлена)
🛠️ Стек

    Golang
    Стандартная библиотека (net/http, html/template, log, strings, time)

🚀 Запустить приложение можно командой:

go run main.go
