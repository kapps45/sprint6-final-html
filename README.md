# 📡 Morse Converter

Веб-сервис на **Go** для преобразования текстовых файлов между обычным текстом и азбукой Морзе.

Приложение принимает файл через веб-интерфейс, анализирует его содержимое, определяет направление преобразования и формирует новый файл с результатом.

Проект построен с разделением HTTP-слоя и бизнес-логики: обработка запросов вынесена в `handlers`, логика преобразования — в `service`, а работа с кодом Морзе — в отдельный пакет.

## ✨ Возможности

- 📤 Загрузка текстовых файлов через HTML-форму
- 🔍 Автоматическое определение формата входных данных
- 🔤 Преобразование обычного текста в код Морзе
- 🔄 Обратное преобразование кода Морзе в текст
- 🇷🇺 Поддержка русского алфавита
- 💾 Сохранение результата обработки в отдельный файл
- 🌐 Работа через HTTP-интерфейс

## 🏗️ Архитектура

Логика приложения разделена на несколько уровней:

| Компонент | Ответственность |
|---|---|
| `server` | Создание и запуск HTTP-сервера |
| `handlers` | Приём HTTP-запросов, загрузка файлов и формирование ответа |
| `service` | Определение типа входных данных и выбор направления преобразования |
| `pkg/morse` | Преобразование текста и работа с таблицей символов Морзе |

Такое разделение позволяет не смешивать HTTP-обработку с основной логикой приложения и упрощает дальнейшее расширение проекта.

## 🔄 Как работает приложение

1. Пользователь открывает веб-интерфейс.
2. Загружает текстовый файл.
3. Сервер получает содержимое файла через HTTP-запрос.
4. Сервис определяет, является ли содержимое обычным текстом или кодом Морзе.
5. Выполняется соответствующее преобразование.
6. Результат сохраняется в файл.
7. Пользователь получает обработанный результат.

## 🚀 Запуск

Запустить приложение можно командой:

    go run ./cmd/main.go

После запуска откройте веб-интерфейс сервиса в браузере.

## 🎯 Цель проекта

Проект предназначен для практики разработки HTTP-сервисов на **Go**, работы с загрузкой файлов, разделения приложения на слои и реализации отдельной бизнес-логики для преобразования данных.
