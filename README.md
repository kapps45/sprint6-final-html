# 📡 Morse Converter

HTTP-сервис на **Go** для загрузки текстовых файлов и преобразования их содержимого между обычным текстом и **кодом Морзе**.

Приложение предоставляет веб-интерфейс, автоматически определяет формат входных данных и сохраняет результат обработки в локальный файл.

## 🔧 Возможности

- 📤 Загрузка файлов через HTML-форму
- 🔍 Автоматическое определение типа содержимого
- 🔤 Преобразование текста в код Морзе
- 🔄 Обратное преобразование кода Морзе в текст
- 🇷🇺 Поддержка русского алфавита
- 💾 Сохранение результата в локальный файл

## 📦 Структура проекта

| Компонент | Назначение |
|---|---|
| `server` | Создание и настройка HTTP-сервера |
| `handlers` | Обработка HTTP-запросов и загрузки файлов |
| `service` | Определение формата данных и выполнение преобразования |
| `pkg/morse` | Работа с кодом Морзе |

## 🛠️ Используемые технологии

- **Go**
- `net/http`
- `html/template`
- `log`
- `strings`
- `time`
